## Governance rules

1. Every copied or adapted code snapshot must be pinned to an exact revision before intake.
2. Preserve applicable upstream license, copyright, NOTICE, and attribution material.
3. Keep third-party dependency licenses separate from the owner's donor authorization.
4. Do not import donor names, logos, trademarks, telemetry endpoints, cloud credentials, or hosted-service assumptions as Lilac identity.
5. Prefer subsystem extraction over whole-repository copying when a smaller boundary provides the needed capability.
6. Every donor-derived subsystem must have tests and a provenance record before becoming canonical.
7. Donor code must not silently weaken Lilac's local-first, zero-mandatory-cloud, evidence-first, or security boundaries.
