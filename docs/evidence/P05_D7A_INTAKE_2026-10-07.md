# P05 D7a - Intake review, web semantics, project commit, network gate

Date: 2026-10-07

Issue: #85

## Scope

First slice of Master Plan D7 (website/app intake product experience). Grain 6 (`@lilac/import-stack`) already captures, sanitizes, and converts web content into history-committable proposals with asset provenance and source bindings. D7a adds the product layer that connects it to the rest of Lilac without modifying Grain 6.

Target package: `packages/intake` (workspace dependencies `@lilac/import-stack`, `@lilac/network-policy`, `@lilac/persistence`, `@lilac/history`, `@lilac/document-model`)

## What it adds

- `reviewImport(proposal)`: deterministic review before commit with node, asset, resource, and stylesheet counts, the sanitization summary (scripts, dangerous elements, handlers, URLs, styles removed), diagnostics by severity with node references (first 200 items), source-binding coverage, semantic role counts, and a `commitReady` verdict. Any error diagnostic or an empty proposal blocks, with reasons.
- `inferSemantics(proposal)`: roles derived only from markup, each recorded with evidence `OBSERVED` and its source (`tag:nav`, `aria-role:button`, `input-type:checkbox`, `tag:a+href`). Allow-listed ARIA roles override native semantics (recorded as overrides); `presentation`/`none` remove a role; unknown roles are reported and never applied. Headings carry levels (native or `aria-level`), images record whether `alt` was present, and accessible names come from `aria-label`/`alt`. Anchors are links only when Grain 6 recorded an `href` resource for them. Grain 6 removes `<form>` elements, so a form landmark can only come from an explicit `role="form"`.
- `commitIntake(store, proposal, { transactionId, at })`: refuses not-ready proposals, computes the import with `@lilac/import-stack`'s `commitImportProposal` against the store's current document and revision, adds the semantics to the committed nodes' props, and persists through `@lilac/persistence`, which re-validates the transaction through history. Stale or conflicting commits write nothing.
- `planNetworkImport(networkPolicy, url)`: asks `@lilac/network-policy` for an `import.fetch` decision; a denial means no import; an allowed loopback decision maps to the import-stack `local-app` policy, otherwise `remote`. Callers must still apply `evaluateResolved` to the addresses they connect to. This is the first production consumer of the D6b policy; import-stack's own network paths are not yet routed through it (#83).

## Offline guarantee

`tests/offline-guarantee.test.mjs` now also reviews the offline HTML import, commits it into the project through intake, and verifies it after reopen, all with every network and process primitive trapped and zero network attempts.

## Non-goals

No changes to Grain 6 capture or sanitization, no responsive or interaction inference, no model-based inference, no UI.
