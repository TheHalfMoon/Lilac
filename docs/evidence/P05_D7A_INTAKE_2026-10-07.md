# P05 D7a - Intake review, web semantics, project commit, network gate

Date: 2026-10-07

Issue: #85

## Scope

First slice of Master Plan D7 (website/app intake product experience). Grain 6 (`@lilac/import-stack`) already captures, sanitizes, and converts web content into history-committable proposals with asset provenance and source bindings. D7a adds the product layer that connects it to the rest of Lilac without modifying Grain 6.

Target package: `packages/intake` (workspace dependencies `@lilac/import-stack`, `@lilac/network-policy`, `@lilac/persistence`, `@lilac/history`)

## What it adds

- `reviewImport(proposal)`: deterministic review before commit with node, asset, resource, and stylesheet counts, the sanitization summary (scripts, dangerous elements, handlers, URLs, styles removed), diagnostics ordered by severity with node references (first 200 items, with a truncation count), source-binding coverage, semantic role counts, and a `commitReady` verdict. Any error diagnostic or an empty proposal blocks, with reasons. The review is advisory: diagnostics and the security summary are carried by the proposal and a tampered proposal can hide them; the integrity guarantee is that `@lilac/import-stack` re-validates every node's content at commit.
- `inferSemantics(proposal)`: roles derived only from markup by walking the tree in document order, each recorded with evidence `OBSERVED` and its source (`tag:nav`, `aria-role:button`, `input-type:checkbox`, `tag:a+href`). Native mappings follow HTML-AAM: `header`/`footer` are banner/contentinfo only when not inside article, aside, main, nav, or section elements or the main, navigation, complementary, region, or article roles; `ul`, `ol`, and `menu` are lists and `li` is a listitem only inside a list role; `img alt=""` is decorative (no role); input types (matched ASCII case-insensitively) map to textbox (text, email, tel, url, or a missing type; an invalid type is a textbox with source `input-type:invalid`), searchbox, spinbutton, checkbox, radio, button, or combobox (with `list`), and password has no role; `select` with `multiple` (`tag:select+multiple`) or a `size` above 1 under HTML non-negative integer parsing (`tag:select+size`) is a listbox. Role tokens are split on ASCII whitespace and compared ASCII case-insensitively (first 8 considered); the first allow-listed token wins (override recorded, earlier unknown tokens reported); `presentation`/`none` remove a role; `article` removes native semantics and scopes header/footer; unknown roles are never applied. Headings carry levels with `aria-level` taking precedence; a non-`h1`-`h6` element with `role="heading"` and no valid `aria-level` defaults to level 2. Accessible names come from `aria-label`/`alt`: format characters (bidi, zero-width, tags) are removed, control and separator characters and whitespace runs collapse to one space, and names are limited to 200 code points. Anchors are links only when Grain 6 recorded an `href` resource for them. Grain 6 neutralizes `<form>` elements into `<div>` (counted in `dangerousElementsRemoved` and reported by a `form-element-neutralized` diagnostic since #86), so a form landmark can only come from an explicit `role="form"`.
- `commitIntake(store, proposal, { transactionId, at })`: reads the proposal once into an inert structured clone and validates it once, so the review, the transaction, and the semantics all describe the same data; refuses not-ready proposals, computes the import with `@lilac/import-stack`'s `commitImportProposal` against the store's current document and revision, adds the semantics to the committed nodes' props, and persists through `@lilac/persistence`, which re-validates the transaction through history. Stale or conflicting commits write nothing.
- `planNetworkImport(networkPolicy, url)`: asks `@lilac/network-policy` for an `import.fetch` decision; a denial means no import; an allowed loopback decision maps to the import-stack `local-app` policy, otherwise `remote`. The returned import policy is generic for its mode and never looser than the decision (remote mode refuses private addresses even when a grant allows them). Since #83, callers pass the same policy as the import request's `networkPolicy` and import-stack enforces it on every contact, so the plan is an early answer rather than the enforcement point.

## Offline guarantee

`tests/offline-guarantee.test.mjs` now also reviews the offline HTML import, commits it into the project through intake, and verifies it after reopen, all with every network and process primitive trapped and zero network attempts.

## Non-goals

No changes to Grain 6 capture or sanitization, no responsive or interaction inference, no model-based inference, no UI.
