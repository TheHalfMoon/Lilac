# P08-G9: integrated security re-test

Issue: #230 (P08 umbrella), founder section P08.9: an integrated security re-test with the existing primitives.

**Status:** the primitives were re-tested together against Ninerr running as a person runs it, with its editor open in a real browser and two hostile neighbours. Every attack failed closed, and nothing changed or left the computer. **No new escape was found.** The test is `tests/security-integrated.test.mjs`; it runs in CI on Linux, Windows and macOS.

## The set-up
- **Ninerr:** started as `npm start` starts it (`scripts/ninerr.mjs`), under the no-network trap (`tests/support/no-network.mjs`). The trap records any connection Ninerr's own code makes off the computer.
- **The editor:** opened from the printed launch link in Chromium (Edge locally). A project is created and edited.
- **The attacker's page:** served from another origin on the same computer, in the same browser, while the editor is open.
- **What Ninerr answered** each of the page's requests is recorded:
  - for writes, from Playwright's responses;
  - for reads and the event stream, from Chromium's own network events (`Network.responseReceivedExtraInfo`). The browser blocks those under CORS, so the page itself never sees an answer.

  What the browser lets the page see is therefore not the evidence.

## What was tried, and what held

| Attack | What stops it | Result |
|---|---|---|
| A foreign page reads `/api/session` and `/api/projects`, and `/api/session` again through `localhost` | Ninerr's `Origin` check (403). The browser would also refuse the read, since Ninerr sends no CORS headers. | 403 for each through `127.0.0.1`. The page reads nothing. Through `localhost`, the read got a 403 too where `localhost` resolves to `127.0.0.1` (every run so far); where it resolves only to `::1`, it cannot connect, since Ninerr listens on `127.0.0.1` only. |
| Bodiless POSTs (`no-cors`): undo, close the project, checkpoint | Ninerr's `Origin` check (403). With no body, no media-type check applies, so these are the writes the guards alone stand in front of. | 403 for each; the project is still open, at revision 1 |
| POSTs with a `text/plain` body (`no-cors`): create a project, an MCP tool call | `Origin` check (403). The `/api/*` media-type check (415) and the agent credential sit behind it. | 403 for each; nothing created |
| A cross-origin form post to create a project (Chromium sends its `Origin`) | `Origin` check (403) | 403; nothing created |
| The page follows the live changes (`EventSource /api/events`) | `Origin` check (403) | 403 |
| A launch link that was already used (from shell history, say) | Single-use launch tickets: `/api/launch` answers 401, where a missing origin would be 403 | 401; the editor does not open, and says to open Ninerr from its launcher |
| Requests sent outside a browser's rules:<br>- `Host: evil.example:<port>`, the name a DNS-rebinding page would send;<br>- `evil.localhost`;<br>- another port's name | `Host` check (421) | 421 for each |
| A foreign `Origin`, or `Origin: null` (a sandboxed frame or a `data:` page) | `Origin` check (403) | 403 |
| No `Origin` (how `<img>`, `<script src>` or a non-browser client asks) and no token, on `/api/session`, `/api/projects`, `/api/events` and a bodiless undo | Studio token (401) | 401 for each |
| No agent credential on `/mcp` | Agent credentials (401) | 401 |
| Another site frames the editor (clickjacking) | `frame-ancestors 'none'` in the editor's CSP | Present |
| An imported HTML file with:<br>- a script and a meta refresh;<br>- `onclick` and `onerror` handlers;<br>- SVG `onload` and `javascript:` links;<br>- an iframe, object, embed, form and `<base>`;<br>- remote stylesheets, prefetch, images and CSS `url()` | Four layers: the import's sanitizer, the renderer's allowlists, the canvas frame's sandbox (no `allow-scripts`) and its `default-src 'none'` policy. The policy also stops `url()` in inline styles, which the DOM checks do not cover. | None of it arrives: no element, handler or script link. Clicking runs nothing, and no request is made |
| Anything reaching off the computer during all of the above | The editor's CSP, the network trap, the browser route recorder | Nothing from the editor's page, the attacker's page or Ninerr's code |

**The test is not vacuous.** Hand mutations to `packages/studio-host/src/server.ts` and `packages/renderer/src/index.mjs` each fail it, and each was restored:
- **The `Origin` check removed alone, and all three host guards removed at once:** the browser part fails, because Ninerr's answers to the foreign page are no longer 403. The first version of this test missed this: its reads and its `text/plain` writes failed on CORS and on the media-type check whatever the guards did. The review caught it, and the bodiless writes and recorded statuses were added.
- **The token check or the `Host` check removed alone:** the requests sent outside a browser's rules catch each.
- **A canvas frame that allows scripts:** only the explicit check of the frame's sandbox catches it. The import's and the renderer's allowlists already strip every script and handler, so the sandbox is a second layer, checked on its own.

**Not attackable today:** the editor listens for no `message` events, and the canvas frame runs no script, so `postMessage` offers nothing to a hostile page or import.

## Covered by the existing suites, unchanged here
- **Agents:** grants, revocation, confirmations and project scope: `tests/mcp-authorization.test.mjs`, `tests/mcp-server.test.mjs`, `tests/project-scope.test.mjs`.
- **Files:**
  - project names and paths: `tests/names-paths.test.mjs` (P08-G3d);
  - links, FIFOs and swapped roots in persistence: `tests/persistence.test.mjs` (P06-G5b);
  - worktree, hard-link and evidence roots: `tests/sandbox-surfaces.test.mjs` (P06-G5c);
  - codebase write-back confinement: `tests/writeback-*.test.mjs`;
  - one host per projects folder: `tests/folder-lock.test.mjs`.
- **Network classification and browser scans:** `tests/network-policy.test.mjs`, `tests/browser-proxy.test.mjs` (P06-G5a).
- **The desktop window:** no navigation, windows, permissions, downloads or requests beyond the host: `tests/desktop-shell.test.mjs`. On each platform's packaged app, the release-candidate and resilience journeys (P08-G8) record no egress.

## Not covered here
- **Another local program running as the person,** which can already act as them: outside what Ninerr defends against (`SECURITY.md`).
- **Windows-specific gaps, filed:**
  - **#268:** trusted host files are not checked for owner or other writers;
  - **#266:** policy-enforced browser scans are refused on Windows.
