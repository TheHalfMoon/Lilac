# P08-G9: integrated security re-test

Issue: #230 (P08 umbrella), founder section P08.9: an integrated security re-test with the existing primitives.

**Status:** the primitives were re-tested together against Ninerr running as a person runs it, with its editor open in a real browser and two hostile neighbours. Every attack failed closed, and nothing changed or left the computer. **No new escape was found.** The test is `tests/security-integrated.test.mjs`; it runs in CI on Linux, Windows and macOS.

## The set-up
- **Ninerr:** started as `npm start` starts it (`scripts/ninerr.mjs`), under the no-network trap (`tests/support/no-network.mjs`). The trap records any connection Ninerr's own code makes off the computer.
- **The editor:** opened from the printed launch link in Chromium (Edge locally). A project is created and edited.
- **The attacker's page:** served from another origin on the same computer, in the same browser, while the editor is open.

## What was tried, and what held

| Attack | Primitive that stops it | Result |
|---|---|---|
| A foreign page reads `/api/session` and `/api/projects` | No CORS headers: the browser refuses the cross-origin read. The token check sits behind it. | Refused |
| The same reads through `localhost`, Ninerr's other name | The same | Refused |
| Blind writes (`no-cors`, `text/plain`): create a project, edit, MCP `initialize`, an MCP tool call | `Origin` check (403), studio token (401), agent credential (401) | Nothing changed: still one project, at revision 1 |
| A cross-origin form post to create a project | `Origin` check | Nothing created |
| A foreign page follows the live changes (`EventSource /api/events`) | The token on the event stream | Refused |
| A launch link that was already used (from shell history, say) | Single-use launch tickets | The editor does not open; it says to open Ninerr from its launcher |
| A rebound host name (`Host: evil.example:<port>`), or another port's | `Host` check (421) | Refused |
| A foreign `Origin` with the right `Host` | `Origin` check (403) | Refused |
| No token; no agent credential on `/mcp` | Studio token; agent credentials | 401 for each |
| An imported HTML file with:<br>- a script and a meta refresh;<br>- `onclick` and `onerror` handlers;<br>- SVG `onload` and `javascript:` links;<br>- an iframe, object, embed, form and `<base>`;<br>- remote stylesheets, prefetch, images and CSS `url()` | The import's sanitizer, the renderer's allowlists, the canvas frame's sandbox (no `allow-scripts`) and its `default-src 'none'` policy | The content arrives with none of it. No handler or script link survives, clicking runs nothing, and no request is made |
| Anything reaching off the computer during all of the above | The editor's CSP, the network trap, the browser route recorder | Nothing from the editor's page, the attacker's page or Ninerr's code |

**The test is not vacuous.** Hand mutations to `packages/studio-host/src/server.ts` and `packages/renderer/src/index.mjs` each failed it, and each was restored:
- no token check;
- no `Host` check;
- no `Origin` check;
- a canvas frame that allows scripts.

The sandbox mutation alone is caught only by the explicit check of the frame's sandbox. The import's and the renderer's allowlists already strip every script and handler, so the sandbox is a second layer, and the test now checks it directly.

## Covered by the existing suites, unchanged here
- **Agents:** grants, revocation, confirmations and project scope: `tests/mcp-authorization.test.mjs`, `tests/mcp-server.test.mjs`, `tests/project-scope.test.mjs`.
- **Files:**
  - project names and paths: `tests/names-paths.test.mjs` (P08-G3d);
  - links, FIFOs and swapped roots in persistence: `tests/persistence*.test.mjs` (P06-G5b);
  - worktree, hard-link and evidence roots: `tests/sandbox-surfaces.test.mjs` (P06-G5c);
  - codebase write-back confinement: `tests/writeback*.test.mjs`;
  - one host per projects folder: `tests/folder-lock.test.mjs`.
- **Network classification and browser scans:** `tests/network-policy.test.mjs`, `tests/browser-proxy.test.mjs` (P06-G5a).
- **The desktop window:** no navigation, windows, permissions, downloads or requests beyond the host: `tests/desktop-shell.test.mjs`. On each platform's packaged app, the release-candidate and resilience journeys (P08-G8) record no egress.

## Not covered here
- **Another local program running as the person,** which can already act as them: outside what Ninerr defends against (`SECURITY.md`).
- **Windows-specific gaps, filed:**
  - **#268:** trusted host files are not checked for owner or other writers;
  - **#266:** policy-enforced browser scans are refused on Windows.
