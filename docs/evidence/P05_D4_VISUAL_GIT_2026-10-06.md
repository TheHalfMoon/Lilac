# P05 D4 - Visual Git implementation evidence

Date: 2026-10-06

Issue: #60

## Scope

Design-state versioning over stable identities and content hashes: design snapshots bound to branch and source commit, stable identity and tree validation, structural diffs (added, removed, changed, moved), review comments and design/code links anchored to existing nodes, three-way conflict reports, PR-style acceptance gates bound to the exact head commit, and provenance records from design state to source revision.

Target package:

`packages/visual-git` (zero runtime dependencies; `node:crypto` and `node:util` built-ins only)

## Authority properties

- Visual Git records, compares, and gates; it never executes git, mutates documents, merges branches, renders, or touches the network or filesystem.
- Conflict detection projects a field-level merge internally only to test structural invariants; the projection is never returned, so no merged snapshot is ever produced.
- Snapshot, comment, link, and check text is data, never commands.

## Conflict semantics

Node-level: `content`, `parent`, `delete-modify`, `add-add`, `orphaned-child`.
Structural (edits clean per node that combine into an invalid tree): `cycle`, `invalid-nesting`, `depth-limit`, plus the report-level `exceedsNodeLimit`. `mergeable` is true only when none apply.

## Input hardening

- Inputs must be plain objects or arrays with own data properties only; proxies, accessor properties, and symbol keys are rejected, so a validated value cannot differ from the returned value.
- Text rejects C0/C1 controls and bidi override/isolate characters.
- Link paths are normalized repository-relative ASCII; `..`, absolute, drive, backslash, leading `-`, and `.git` segments are rejected.
- Gates block on `stale-snapshot`, `empty-range` (base equals head), `no-checks`, failing, pending, missing-required, and skipped-required checks.

## Determinism

- Canonical serialization round-trips through `JSON.parse` (the defect tracked in #61 is not copied).
- Identical inputs produce identical snapshots, diffs, reports, and digests; no clocks or random identifiers in core logic.
- Oversized and over-deep inputs fail closed.
