# N0-G7a2: Ninerr is licensed under Apache-2.0

Issue: #190 (N0 umbrella). The founder set the target license on 2026-10-08. Before it could be declared, a source-rights audit had to separate founder-authorized donor sources (A) from independent third parties (B). This record is that audit and the declaration.

## The authorization
`docs/provenance/FOUNDER_AUTHORIZATION_2026-10-08.md` quotes the founder's source authorization and license instruction verbatim. It names the scope: the projects that earlier owner attestations record.
- `PAPER_AUTHORIZATION.md` records Paper.design.
- `AUTHORIZED_DONOR_EXPANSION_2026-10-03.md` records thirteen donor projects.

## The audit
N0-G7a1 (#214, `docs/evidence/N0_G7A1_SOURCE_CATEGORIES_2026-10-09.md`) gave every entry in `docs/provenance/LICENSE_REGISTER.json` a `category`. `tests/license-register.test.mjs` checks the classification against the authorization records.

**Category A: 14 entries.** These are the authorized projects' own sources; Paper has two entries, `paper.design` and `paper-design/paper`.
- Their use in Ninerr rests on the founder's authorization.
- By the register's own kinds, none of them is vendored. Code donors contributed adapted patterns in Ninerr-authored source. Guidance and reference donors contributed nothing copied.

**Category B: 25 entries.** Each is governed by its own license.
- **Shipped npm dependencies:**
  - `parse5` and `entities`;
  - the `impeccable` package and its five platform binaries;
  - `playwright-core`.

  The `impeccable` package is Apache-2.0 and stays category B as a dependency, although its upstream project is an authorized donor.
- **The Electron runtime.**
- **Optional runtimes** Ninerr does not ship, including the Docling CLI. Its upstream project is authorized, but the runtime the user installs is not covered by that.
- **Development tooling.**
- **Public repositories** that were studied, are outside the authorized set, and from which nothing was copied.

## The two Paper entries
They were marked `founder-confirmation-required`, and that blocked the declaration. The register asked whether the authorization permits distributing and sublicensing Ninerr's Paper-compatible interfaces and behaviour.
- The founder's authorization gives permission to redistribute, rebrand, rename and incorporate the authorized source.
- The founder did not say "sublicense". This record does not claim the founder did.
- The question no longer turns on that word, because no Paper material remains to be sublicensed:
  - no commit ever touched an `imports/` path;
  - N0-G4 replaced the recorded Paper MCP tool names with Ninerr's own catalog;
  - N0-G5 retired every Paper recovery record.
- What remains is behaviour compatibility implemented in Ninerr-authored code. The Apache-2.0 grant therefore covers Ninerr's own work only.

Both entries are now `compatible: "yes"` as category A. Each gives that reasoning in its `resolution`, and its obligations say that Paper's names and marks are not licensed to Ninerr and that no Paper material is distributed. The register test admits a proprietary entry as compatible only on those terms.

## The declaration
- **`LICENSE`** is the Apache License 2.0 text as the ASF publishes it (https://www.apache.org/licenses/LICENSE-2.0.txt). It is byte-identical: SHA-256 `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`, which the register test checks. `.gitattributes` keeps it LF, so every checkout has those bytes.
- **License metadata.** The root `package.json` and all 26 workspace packages declare `"license": "Apache-2.0"`, and so do their lockfile entries.
- **Shipping.**
  - The desktop app ships `LICENSE` in its app folder, and the app's `package.json` declares the license. Electron's own license stays beside the executable.
  - The release bundle includes `LICENSE`.
  - `MANIFEST.json`'s `projectLicense` and the SBOM's root component now carry `Apache-2.0` from `package.json`. Both scripts read the declared license instead of guessing one. The SBOM's 26 first-party package components had still hardcoded "no assertion"; each now carries its package's declared license, and `tests/sbom.test.mjs` checks every one. (Raised by the N0-G7a2 review panel.)
- **Docs.** `docs/RELEASE.md` states the license. `docs/DONORS.md` now describes the public `paper-design/*` repositories as studied, separately licensed and not incorporated.
