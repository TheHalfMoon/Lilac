# Lilac

Lilac is an AI-native design workspace built around a bidirectional design ↔ code loop.

The project is being initialized as a clean, independently branded product. Paper.design is an authorized source/donor for Lilac, subject to source provenance, third-party license preservation, and trademark/branding separation.

## Current state

This repository has been bootstrapped for implementation. The complete Paper product source is not present in the connected GitHub sources yet; therefore no unavailable Paper product code is represented here as imported or reconstructed.

The first implementation program establishes:

- an evidence-backed donor inventory;
- an import and provenance pipeline for authorized source drops;
- a target architecture for canvas, document model, rendering, collaboration, agents/MCP, code synchronization, desktop, and persistence;
- a parity matrix for Paper capabilities;
- Lilac-native differentiation beyond parity;
- quality, security, accessibility, and performance gates.

See `docs/` after the bootstrap program lands.

## Product direction

Lilac should preserve the strongest properties of a web-native design canvas while becoming a deeper engineering surface:

- real HTML/CSS semantics;
- code components as first-class design primitives;
- bidirectional code/design synchronization;
- local-first agent integration through MCP;
- visual Git-style history and review;
- multi-agent design, implementation, accessibility, and QA workflows;
- deterministic export and round-trip safety;
- local/private operation as a first-class mode.

## Integrity rule

Do not claim that Paper product source has been imported unless the exact source artifact, provenance, revision, and rights record are present in this repository's evidence ledger.
